# HR Analytics Dashboard

This project focuses on analyzing HR data to uncover insights related to employee attrition, demographics, performance, and job satisfaction. Using Power BI, the dataset was cleaned, transformed, and visualized to create an interactive dashboard that helps HR teams make data-driven decisions.

---

## 📊 Project Overview
The HR Analytics Dashboard provides:
- Attrition analysis by age, department, and job role  
- Employee demographic insights  
- Performance and job satisfaction trends  
- Key HR metrics such as average salary, employee count, and retention rate  
- Interactive filters for deeper HR workforce analysis  

---

## 🛠 Tools & Technologies
- **Power BI**
- **Excel / CSV**
- **Data Modeling (DAX, Power Query)**

---

## 📁 Files Included
- `HR_Data.xls` – Raw dataset  
- `HR_Analytics Dashboard.pbix` – Complete Power BI dashboard file  

---

## 🔍 Key Insights
- Identified main factors contributing to employee attrition  
- Analyzed workforce distribution across departments  
- Highlighted salary patterns and performance relationships  
- Built visual dashboards for HR decision-making  

---

## 🚀 Features
- Clean, interactive visualizations  
- Easy-to-use slicers for HR managers  
- Automated measures using DAX  
- Optimized data model for smooth performance  

---

## 📌 How to Use
1. Download the `.pbix` file from this repository.  
2. Open it in **Power BI Desktop**.  
3. Explore the dashboard using filters and visual elements.
